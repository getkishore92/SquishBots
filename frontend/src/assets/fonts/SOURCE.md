Satoshi by Indian Type Foundry. Family: https://www.fontshare.com/fonts/satoshi. Run `npm run setup:fonts` to download the unmodified variable WOFF2 fonts and original FFL.txt from https://api.fontshare.com/v2/fonts/download/satoshi. Font binaries are local build inputs excluded from Git. They retain the ITF Free Font License and are not covered by the project MIT license. Used for this application interface, not offered as an avatar customization font.
