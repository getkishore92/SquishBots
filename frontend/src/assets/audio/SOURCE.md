# Avatar sound prototype

`capsule-happy.wav` is the first 1.03 seconds of the user-supplied Suno file
`Two Cheerful Creature Squeaks.mp3`. The user confirmed that the opening contains
two clean squeaks. Converted to mono 44.1 kHz PCM, with short edge fades and a
peak limiter. The original download is not bundled.

Only Capsule / Happy currently has a clip. Other combinations stay silent.
Add future clips as `<shape>-<expression>.wav` to use the same playback path.
